# CEDIVEP results portal

Portal where veterinary clinics log in with a one-time code and see their lab results.

```bash
npm install
npm run dev        # http://localhost:3000 — demo data, log in with 0981 000 001
npm test           # unit tests
npm run test:e2e   # build + end-to-end tests
```
